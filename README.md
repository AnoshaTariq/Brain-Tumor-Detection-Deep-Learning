# Brain Tumor Classification

This Hugging Face Space uses a pretrained model VGG16 and use data sets brain tumor mri from kaggle

## Files Required

Upload these files to your Hugging Face Space:

1. `app.py`
2. `requirements.txt`
3. `brain_tumor_mri_vgg16_finetune.h5`



## Features

- Upload image
- Capture image from webcam
- Adjust confidence threshold
- Display bounding boxes
- Show detection summary
- Create MRI report in pdf format
